Learn HoloNET

Build .NET apps, sites and games on Holochain, one tutorial at a time.

Step-by-step tutorials for building on Holochain with .NET: each one takes you from nothing to something that works, using code that HoloNET runs against real Holochain 0.7.0 and 0.7.1 conductors on every release.

1. Up and running in 5 minutes

a working .NET app that saves and loads data on Holochain, from one command, in the kind of app you already build (web, desktop, mobile, game).

5 minutes

2. Your first zome call

a .NET console app that connects to Holochain, installs a hApp, writes an entry, reads it back, and receives a signal from another agent.

15 minutes

3. Save data in one line

an app that saves, loads and deletes settings and objects on Holochain, with no Rust, no zome calls and no setup code.

10 minutes

4. Model your data with the ORM

a C# class that maps onto a hApp entry: save it, load it, change it (with change tracking), delete it, and keep lists of them in collections.

20 minutes

5. A live web site on Holochain

an ASP.NET Core site with a guestbook and a leaderboard that every visitor shares, stored on Holochain and updated instantly in every open browser.

25 minutes

6. Real-time multiplayer with HyperNET

a game loop where players in a zone see each other move and exchange messages directly, peer to peer, with no game server. Only nearby players get your traffic.

25 minutes

7. Generate a hApp from your classes

a complete Holochain 0.7 hApp (the Rust zomes, manifests and a build script) and the matching C# models, generated from a description of your data. You don't write any Rust.

20 minutes (plus the first Rust build)

8. A template for every app

You'll learn: how each kind of .NET app calls HoloNET, so you can drop HoloNET into the app you already have. Time: 10 minutes. You need: Up and running in 5 minutes done once. The templates: templates/ · Templates refer

10 minutes
