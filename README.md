# Learn HoloNET website

**[learn.holonet.oasisomniverse.one](https://learn.holonet.oasisomniverse.one)**: step-by-step tutorials for building .NET apps, sites and games on Holochain with HoloNET.

This site is **generated**. Don't edit the HTML here. Edit the tutorials in [holochain-client-csharp](https://github.com/holochain-open-dev/holochain-client-csharp) (`docs/learn/`), then rebuild:

```bash
python scripts/build-sites.py      # in holochain-client-csharp, with this repo checked out next to it
```

Commit and push here. Vercel deploys the static files (`vercel.json`).
